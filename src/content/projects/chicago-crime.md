Large-scale big data platform for processing and analyzing Chicago crime datasets using distributed computing infrastructure. Built scalable ETL pipelines with Hive for data warehousing and Scala for distributed data processing. Implemented efficient data ingestion, transformation, and aggregation workflows supporting high-throughput batch processing and real-time analytics on petabyte-scale datasets.
